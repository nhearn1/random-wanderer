Random Wanderer - Updated Build
===============================

Fixes & Features
----------------
1. Class selection now prompts at Level 5 (Warrior / Mage / Rogue) with ability unlocks.
   Subclass selection at Level 20 (Tank/Blademaster/Veteran, Warlock/Cleric/Pyromancer, Assassin/Thief/Duelist).

2. Boss stats boosted (HP/ATK/DEF multipliers ~1.6–2.0). Each act boss should feel much tougher.

3. Storyline flavor text expanded (messenger, king, Kaelen, seer).

4. Finale endings now ALL trigger a boss fight:
   - Hero    -> Royal Champion
   - Rebel   -> High Inquisitor
   - Wanderer-> Shadow Remnant
   - Kaelen duel -> Kaelen himself

5. Towns unlock with story:
   - Act I  -> Homestead (starting town)
   - Act II -> Bluewater (after Bear)
   - Act III-> Stonefield (after Warlord)
   - Act IV -> Frostgate (after Chieftain)
   - Act V  -> Capital (after General)

6. Crafting (Workshop) system added:
   - Healing Tonic: herbs(1) + mushrooms(1)
   - Tempered Edge (+1 weapon tier): ore(2) + 30g
   - Reinforced Plate (+1 armor tier): ore(2) + driftwood(1) + 30g
   - Shield Boss (+1 shield tier): ore(1) + 20g

7. Exploration areas locked by STORY, not level. Fixed bug so only ONE new region unlocks per act.

---
Usage
-----
- Drop these files into your project folder, overwrite existing ones.
- Run `python main.py` to play.
